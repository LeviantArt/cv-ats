# CV ATS Template

A clean, professional, and ATS-friendly Curriculum Vitae (CV) template built using **HTML5** and **CSS3**. This template is designed for creating modern resumes that are easy to read by both recruiters and Applicant Tracking Systems (ATS), while maintaining a clean and print-ready layout.

---

## ✨ Features

- ATS-friendly design
- Professional and minimalist layout
- A4 paper size (210 × 297 mm)
- Print-ready and PDF-friendly
- Semantic HTML5 structure
- CSS Design Tokens (CSS Variables)
- Google Fonts integration
- Bootstrap Icons support
- Easy to customize
- Clean and maintainable code

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/LeviantArt/cv-ats.git
```

### Open the project

Simply open the `index.html` file in your preferred web browser.

### Customize

Replace the sample information with your own:

- Personal Information
- Contact Information
- Professional Summary
- Education
- Work Experience
- Skills

### Export to PDF

Use your browser's **Print** feature and choose **Save as PDF**.

The template has been optimized for A4 paper size.
